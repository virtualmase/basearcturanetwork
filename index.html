NO EXECUTION
What is active now?
A static descriptor at /gateway.json, a static health declaration at /health.json, and public Base Sepolia documentation links. Those routes describe current scope; they do not accept input.
What is deliberately disabled?
Wallet creation and connection, custody, balance access, payments, transfers, swaps, signing, contract calls, autonomous execution, mainnet, and x402 fulfillment are all disabled in the public descriptor.
How would future activation work?
A future test requires a named Base Sepolia receiver, an approved facilitator, a capped resource, specific human approval, a reviewable receipt, and a separate production decision. None of those controls are configured here.
Authority boundary

A signal is useful only when its limits are part of the interface.

This gateway exists to make boundaries obvious before any irreversible action is possible. It is a live reference surface—not a bank, exchange, token sale, custody service, trading terminal, or investment product.

×
No wallet credentials

×
No implicit financial authority

No funding, transfer, swap, trade, payment, signing, contract call, or automatic payout can originate from this interface.
